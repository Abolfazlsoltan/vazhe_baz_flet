# واژه‌باز | Vazhe-Baz 🎯

بازی حدس کلمه فارسی با Flet و Python؛ تک‌نفره، دونفره محلی و اتاق آنلاین با FastAPI.

## امکانات
- حروف فارسی شامل «آ»؛ نرمال‌سازی ک/ك و ی/ي
- خانه‌های حروف اشتباه زیر کلمه و از چپ به راست
- تعداد خطاهای مجاز برابر تعداد حروف قابل حدس کلمه
- تایمر مبتنی بر asyncio که با خروج از بازی لغو می‌شود
- ذخیره دائمی امتیاز و آمار محلی در SQLite
- بازی دونفره نوبتی روی یک دستگاه
- API اتاق آنلاین با کد دعوت و دو بازیکن

## اجرای بازی
Python 3.10 تا 3.12:
\`\`\`bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
\`\`\`

## اجرای سرور آنلاین
\`\`\`bash
uvicorn server:app --host 0.0.0.0 --port 8000
\`\`\`
سلامت سرور: \`http://127.0.0.1:8000/health\`. برای بازی با دوست از راه دور، سرور را روی میزبان عمومی مستقر کنید و آدرس قابل دسترس آن را در صفحه آنلاین وارد کنید؛ localhost فقط همان دستگاه است. اتاق‌ها فعلاً در حافظه هستند و با راه‌اندازی مجدد سرور پاک می‌شوند. پیش از انتشار عمومی، احراز هویت، محدودسازی درخواست‌ها، ذخیره‌سازی پایدار و بررسی امنیتی اضافه شود.

## ساخت APK
\`\`\`bash
flet build apk
\`\`\`
یا از GitHub Actions استفاده کنید؛ APK به‌صورت artifact ارائه می‌شود.
